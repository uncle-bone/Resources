# Resources

WoW Forever addon projects and research maintained by Uncle Bone.

## ClassResourcesForever

A class-aware resource, cooldown, and proc alert addon (version 0.3.8). The seven non-Druid/Rogue classes use a repurposed copy of the permitted DruidResources tracker code; Druid and Rogue retain their original imported modules.

**Download source archive:** [Resources main ZIP](https://github.com/uncle-bone/Resources/archive/refs/heads/main.zip) — install the `ClassResourcesForever/` folder inside the archive.

Move mode includes a **Move everything together** option that makes dragging the main tracker carry detached class alerts and proc icons with it.

See [ClassResourcesForever/README.md](ClassResourcesForever/README.md) for features, proc coverage, and install instructions.
