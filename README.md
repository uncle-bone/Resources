# Resources

WoW Forever addon projects and research maintained by Uncle Bone.

## ClassResourcesForever

A class-aware resource and cooldown tracker for all nine WoW Forever classes. Druid and Rogue use the permitted Konchius trackers; the other seven classes use the shared class tracker with configurable cooldown layout.

**Download:** [ClassResourcesForever-0.2.0.zip](https://github.com/uncle-bone/Resources/raw/refs/heads/main/downloads/ClassResourcesForever-0.2.0.zip)

See [ClassResourcesForever/README.md](ClassResourcesForever/README.md) for features, installation, controls, and validation status.
