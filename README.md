# Resources

WoW Forever addon projects and research maintained by Uncle Bone.

## ClassResourcesForever

A class-aware resource and cooldown addon. Druid and Rogue retain the permitted Konchius trackers. The other seven class trackers repurpose the DruidResources bar UI and the imported cooldown layout patterns.
