# ClassResourcesForever

A single class-aware resource and cooldown addon for WoW Forever. The addon detects the player's class and loads the matching tracker for all nine Forever classes.

- Druid and Rogue modules import the existing Konchius addons, adapted with class-specific namespaces and separate callbacks. Their full standalone feature sets are retained.
- Warrior, Paladin, Hunter, Priest, Shaman, Mage, and Warlock use the shared resource and learned-cooldown framework.
- The repository includes the original addon source, documentation, changelogs, and licenses, plus a permission record based on the screenshots supplied by the maintainer.

See the [addon source](ClassResourcesForever/) for install and feature details. Initial version: 0.1.0; current live-client validation is still pending.
